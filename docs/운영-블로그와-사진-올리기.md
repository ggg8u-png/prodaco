# 블로그 글 · 시공 사진 올리기 (운영자용)

주소는 `https://prodaco.kr/admin/` 입니다. 넷리파이 계정으로 로그인하세요.

---

## 1. 블로그 글 쓰기 — ⑧ 블로그 글

**입력할 것은 제목과 본문, 두 개뿐입니다.**

1. `⑧ 블로그 글` → 오른쪽 위 **New 블로그 글**
2. **제목** 을 씁니다.
3. **본문** 을 씁니다. 글자를 드래그한 뒤 위쪽 버튼으로 **굵게 / 기울임 / 링크 / 소제목 / 목록 / 인용** 을 적용합니다.
   사진은 `+` 버튼 → 이미지로 넣습니다.
4. **Publish** 를 누르면 끝. 2~3분 뒤 사이트에 반영됩니다.

자동으로 채워지는 것:

| 항목 | 어떻게 되는가 |
| --- | --- |
| 주소(URL) | 제목에서 자동 생성 — "타일 철거 비용" → `prodaco.kr/blog/타일-철거-비용` |
| 작성일 | 오늘 날짜가 미리 들어가 있음 |
| 요약 | 비워두면 본문 앞부분이 검색결과 설명으로 자동 사용 |
| 태그 | 없어도 됨 |
| 카테고리 | 기본값 "정보" |

### 꼭 알아둘 것

- **주소는 처음 저장할 때 한 번만 정해집니다.** 나중에 제목을 고쳐도 주소는 그대로입니다.
  (구글·네이버에 이미 등록된 주소가 바뀌면 순위를 잃기 때문에 일부러 이렇게 해두었습니다.)
- 그래서 **제목은 처음 쓸 때 신경 써서** 쓰고, 이후엔 마음껏 다듬어도 됩니다.
- 주소를 꼭 바꿔야 한다면: 새 글로 다시 쓰고 옛 글을 지운 뒤,
  `netlify.toml` 아래쪽 리다이렉트 예시대로 옛 주소 → 새 주소를 연결해야 합니다(개발자 작업).
- 기호(`##`, `-`, `**`)를 직접 입력해도 되지만, **버튼을 쓰는 쪽이 안전합니다.**

---

## 2. 시공 사진 올리기 — ⑩ 시공 사례(사진)

**지역 → 작업 종류 → 사진 2장. 이게 전부입니다.**

1. `⑩ 시공 사례(사진)` → **New 시공 사례**
2. **지역** 을 목록에서 고릅니다.
3. **작업 종류** 를 목록에서 고릅니다.
4. **철거 전 사진 / 샌딩 후 사진** 을 올립니다. 폰 원본 그대로 올려도 됩니다 —
   사이트에 나갈 때 자동으로 가볍게 줄여서 내보냅니다.
5. **Publish**

ID·제목·주소는 자동으로 만들어집니다. 작업일·설명은 선택입니다.

### ⚠ 지역·작업 종류는 목록에서 고른 값 그대로 쓰세요

이 두 값이 **키워드 페이지의 값과 정확히 일치할 때만** 그 "지역+품목" 페이지가
검색엔진 색인 대상으로 올라갑니다. 사례 1건 = 그 지역+품목 페이지 색인.
그래서 직접 타이핑이 아니라 드롭다운으로 고정해 두었습니다.

### ⚠ "운영자가 직접 확인한 실제 사례" 체크

- **켬(기본)**: 그 지역·그 품목이 실제 그 현장이 맞음 → 색인 승급에 사용됩니다.
- **끔**: 사이트에는 계속 보이지만 색인 승급에는 쓰지 않습니다.

지역이나 공정이 확실하지 않은 사진은 **끄고** 올리세요.
(확실하지 않은 사진을 특정 지역 시공사례처럼 올리는 것은 검색엔진에 위험합니다.)

## 3. 자주 겪는 상황

**Q. 글을 올렸는데 사이트에 안 보여요.**
넷리파이가 다시 빌드하는 데 2~5분 걸립니다. 넷리파이 대시보드의 Deploys 에서 진행 상태를 볼 수 있습니다.

**Q. 사진이 "시공 사진 준비 중" 으로 나와요.**
업로드가 덜 끝났거나 파일이 깨진 경우입니다. 사례를 열어 사진을 다시 올려보세요.

**Q. 글을 지우고 싶어요.**
해당 글에서 상단 **Delete entry**. 이미 검색에 등록된 글이라면 지우기보다 내용을 고치는 편이 낫습니다.

**Q. 색인(구글 검색 등록)을 늘리고 싶어요.**
`⑪ 색인·SEO 설정` 의 숫자를 올려도 늘지 않습니다. **⑩ 시공사례에 실제 사례를 추가하는 것**이
색인을 늘리는 유일한 정상 경로입니다.
